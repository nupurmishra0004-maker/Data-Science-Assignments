## Projects

### 1. Employee Resignation Analysis Using Excel

**Objective:** Analyse employee resignation data and derive summary statistics, trends, and visual insights using Microsoft Excel.

**Dataset:** 5,000 employee resignation records.

**Tools & Techniques:**
- Microsoft Excel
- Data cleaning and formatting
- Excel formulas
- PivotTables and PivotCharts
- Interactive slicers
- Data visualization

**Analysis Covered:**
- Department-wise resignations
- Job role vs. resignation reason
- Gender distribution
- Performance rating analysis
- Employee tenure analysis
- Yearly resignation trends
- Age vs. tenure analysis

**Key Findings:**
- Total recorded resignations: 5,000
- Finance had the highest resignation count: 878
- Better Opportunity was the most common resignation reason: 1,017
- Male employees: 2,520; Female employees: 2,480
- The largest tenure group was 2–4 years: 1,188 employees

**Project File:** `Employee_Resignation_Analysis.xlsx`
