# Employee Resignation Data Analysis Using Python

## Project Overview
This project analyzes 5,000 employee resignation records
to identify patterns and trends in employee resignations.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- OpenPyXL
- Jupyter Notebook
