# Employee Resignation Analysis – SQL Project

## Project Overview
This project analyzes 5,000 employee resignation records using MySQL to identify patterns and derive meaningful insights.

## Tools Used
- MySQL Workbench
- SQL
- Visual Studio Code

## Dataset
- 5,000 employee records
- Employee demographics
- Department and job role
- Joining and exit dates
- Performance ratings
- Resignation reasons
- Last working location

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- ALTER TABLE
- INSERT INTO
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT()
- AVG()
- ROUND()
- CASE statements

## Analysis Performed
- Total resignations
- Average age and tenure
- Department-wise resignations
- Gender-wise resignations
- Resignation reasons
- Year-wise resignation trends
- Performance rating analysis
- Age group analysis
- Location-wise resignations
- High performer resignations

## Key Findings
- Total resignations: 5,000
- Average age: 40.84 years
- Average tenure: 6.47 years
- Finance recorded the highest department-wise resignations.
